# Развёртывание платформы Learn Kids

## Запуск на своей машине

1. Установите Docker и docker-compose.
2. В каталоге проекта:
   ```bash
   cp .env.example .env
   # При необходимости отредактируйте .env (DATABASE_URL, JWT_SECRET)
   docker-compose up --build -d
   ```
3. Приложение будет доступно по адресу **http://localhost:8080** (или по IP вашей машины в локальной сети, например http://192.168.1.100:8080).

### Настройка сети

- Чтобы открывать платформу с других устройств в домашней сети, используйте IP вашего компьютера (например, 192.168.1.100) и порт 8080.
- Для постоянного имени хоста (например, learn-robotics.local) настройте резервацию DHCP по MAC-адресу в роутере и при необходимости локальный DNS (Pi-hole или аналоги).

## Перенос на отдельный сервер

1. На целевом хосте установите Docker и docker-compose.
2. Перенесите в каталог на новом хосте:
   - весь репозиторий (или только `docker-compose.yml`, `Dockerfile.api`, `.env` и при необходимости volume с данными БД),
   - файл `.env` с корректными переменными для нового окружения.
3. Запустите:
   ```bash
   docker-compose up -d
   ```
4. Образы соберутся при первом запуске (или подтянутся с registry, если вы их туда публикуете). Данные PostgreSQL хранятся в volume `db_data` — при переносе тома скопируйте его на новый хост в область данных Docker.

### Переменные окружения

- `DATABASE_URL` — строка подключения к PostgreSQL. В docker-compose для сервиса `api` по умолчанию используется `postgres://postgres:postgres@db:5432/learn_kids?sslmode=disable`.
- `JWT_SECRET` — секрет для подписи JWT (обязательно смените в продакшене).
- `FRONTEND_ORIGIN` — разрешённый origin для CORS (по умолчанию http://localhost:5173; для доступа по IP укажите, например, http://192.168.1.100:8080).

## Остановка и обновление

- Остановка: `docker-compose down`.
- Обновление кода: выполните `git pull` (или скопируйте новые файлы), затем `docker-compose up --build -d` для пересборки и перезапуска.
