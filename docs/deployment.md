# Развёртывание платформы Learn Kids

## Архитектура для локальной сети

Приложение защищено Nginx reverse proxy:

- **Nginx** слушает порт **8888** и принимает запросы только из подсети 192.168.1.0/24 и с localhost.
- Порт 8080 сервиса **api** не пробрасывается наружу — доступ только через Nginx.
- Контейнеры общаются по выделенной Docker-сети `learn_kids_net`.

## Запуск на своей машине (Kubuntu)

1. Установите Docker и docker compose.
2. В каталоге проекта:
   ```bash
   cp .env.example .env
   # Отредактируйте .env: DATABASE_URL, JWT_SECRET, FRONTEND_ORIGIN
   # Для доступа по IP укажите FRONTEND_ORIGIN=http://192.168.1.XXX:8888
   # Для чата с ИИ добавьте GEMINI_API_KEY в .env или в .test.env (если уже есть для тестов)
   [ -f .test.env ] || touch .test.env   # нужен для docker-compose, может быть пустым
   docker compose up --build -d
   ```
3. Приложение будет доступно:
   - локально: **http://localhost:8888**
   - из сети: **http://192.168.1.XXX:8888** (замените XXX на IP сервера в подсети 192.168.1.0/24)

### Разрешение входящего трафика (ufw на Kubuntu)

Чтобы клиенты в локальной сети могли обращаться к приложению, разрешите порт 8888 в ufw:

```bash
# Включить ufw (если ещё не включён)
sudo ufw enable

# Разрешить порт 8888 для входящих соединений
sudo ufw allow 8888/tcp

# Проверить статус
sudo ufw status
```

После этого доступ с Windows (или другого узла в 192.168.1.0/24) по адресу `http://IP_СЕРВЕРА:8888` будет работать.

### Настройка сети

- Доступ ограничен подсетью **192.168.1.0/24** и **127.0.0.1** (см. `nginx/nginx.conf`).
- Если ваша подсеть иная — измените `allow` в `nginx/nginx.conf`.
- Для постоянного имени хоста (learn-robotics.local) настройте резервацию DHCP по MAC-адресу в роутере и при необходимости локальный DNS (Pi-hole или аналоги).

## Перенос на отдельный сервер

1. На целевом хосте установите Docker и docker compose.
2. Перенесите в каталог на новом хосте:
   - весь репозиторий (или минимально: `docker-compose.yml`, `Dockerfile.api`, `nginx/nginx.conf`, `.env` и при необходимости volume с данными БД),
   - файл `.env` с корректными переменными для нового окружения.
3. Запустите:
   ```bash
   docker compose up -d
   ```
4. Образы соберутся при первом запуске (или подтянутся с registry, если вы их туда публикуете). Данные PostgreSQL хранятся в volume `db_data` — при переносе тома скопируйте его на новый хост в область данных Docker.
5. Разрешите порт 8888 в ufw (см. раздел выше).

### Переменные окружения

Сервис `api` загружает переменные из `.env` и `.test.env` (последний дополняет/перезаписывает). Файл `.test.env` должен существовать — создайте пустой (`touch .test.env`), если его нет.

- `DATABASE_URL` — строка подключения к PostgreSQL. В docker compose для сервиса `api` по умолчанию используется `postgres://postgres:postgres@db:5432/learn_kids?sslmode=disable`.
- `JWT_SECRET` — секрет для подписи JWT (обязательно смените в продакшене).
- `FRONTEND_ORIGIN` — разрешённый origin для CORS. Для доступа по IP укажите, например, `http://192.168.1.100:8888` (порт 8888 — порт Nginx).
- `GEMINI_API_KEY` — ключ API Google Gemini для чата с ИИ в уроках. Добавьте в `.env` или `.test.env`. Без него чат недоступен.

## Остановка и обновление

- Остановка: `docker compose down`.
- Обновление кода: выполните `git pull` (или скопируйте новые файлы), затем `docker compose up --build -d` для пересборки и перезапуска.
