# Домен: Каталог уроков (модули, уроки, шаги, материалы)

**Обновлено:** 2026-02-27

## Назначение

Каталог учебного плана: дерево модуль → урок → шаги; материалы и теги к урокам. Только чтение для учеников. Создание и редактирование модулей и уроков — только **владелец курса** (creator или назначенный в `modules.owner_id`) или **администратор**.

## Контракт API

- `GET /api/v1/modules` — список модулей. Query: `platform`, `tag`, `mine` (опционально). При `mine=true` и авторизации возвращаются только модули, где текущий пользователь владелец (`owner_id`). В ответе у каждого модуля может быть поле `is_owner` (true, если текущий пользователь — владелец).
- `POST /api/v1/modules` — создать курс (JWT, создатель становится владельцем). Тело: `{ "title", "description?", "sort_order?" }`.
- `DELETE /api/v1/modules/:id` — удалить курс и все его уроки. Только владелец модуля или administrator.
- `GET /api/v1/modules/:id` — один модуль с вложенными уроками. При авторизации в ответе поле `is_owner` (true, если текущий пользователь — владелец).
- `POST /api/v1/modules/:id/lessons` — добавить урок в курс. Только владелец модуля или administrator. Тело: `{ "title", "description?", "lesson_type?", "sort_order?", "steps?" }`.
- `GET /api/v1/lessons/:id` — урок по id (включая шаги, материалы, теги, чек-лист; счётчики лайков/дизлайков и `user_reaction` при авторизации).
- `PUT /api/v1/lessons/:id` — обновить урок. Только владелец модуля или administrator.
- `DELETE /api/v1/lessons/:id` — удалить урок. Только владелец модуля или administrator.
- `PUT /api/v1/lessons/:id/reaction` — поставить лайк/дизлайк уроку. Тело: `{ "reaction": "like" | "dislike" }`. JWT.
- `DELETE /api/v1/lessons/:id/reaction` — убрать свою реакцию. JWT.

## Связи

- Прогресс (progress) ссылается на `lesson_id` и `user_id`.
- Родительский дашборд читает уроки через тот же API и прогресс по `user_id`.

## Решения

- Модули и уроки отдаются без авторизации (публичное чтение).
- Теги хранятся в таблице `lesson_tags` (lesson_id, tag).
- Тип урока: `theory` | `practice` | `project`.
- **Контент шагов урока** хранится в поле `lesson_steps.content` в формате **Markdown** (GFM). На фронте рендерится через `react-markdown`: абзацы, списки, блоки кода (тройные обратные кавычки), инлайн-код, ссылки, выделение.
- **Картинки**: Markdown `![alt](url)`. Кнопка «Картинка» в редакторе вставляет шаблон.
- **YouTube**: ссылка на YouTube в Markdown (`[текст](https://www.youtube.com/watch?v=ID)` или `[текст](https://youtu.be/ID)`) рендерится как встроенный плеер. Принимаются только домены youtube.com и youtu.be. Кнопка «YouTube» в редакторе вставляет шаблон.

## Владение курсом

- В таблице `modules` поле `owner_id` (UUID, FK на `users`, nullable) — владелец курса. При создании модуля в `owner_id` записывается текущий пользователь.
- Редактирование (создание/изменение/удаление модуля и его уроков) разрешено только если пользователь — **administrator** или **владелец этого модуля** (`modules.owner_id = user_id`). Роль teacher без владения курсом не даёт права редактировать контент.

## Безопасность контента

- Контент шагов (`lesson_steps.content`), заголовки шагов, описания уроков и модулей **санитизируются на бэкенде** (пакет `internal/sanitize`, bluemonday) перед записью в БД: удаляются все HTML-теги, что исключает XSS при любом способе рендера.
- Лимиты длины: заголовок — 500 символов, описание — 10 KB, контент шага — 100 KB, шагов в уроке — не более 200.
