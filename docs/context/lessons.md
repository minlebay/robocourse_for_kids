# Домен: Каталог уроков (модули, уроки, шаги, материалы)

**Обновлено:** 2026-02-17

## Назначение

Каталог учебного плана: дерево модуль → урок → шаги; материалы и теги к урокам. Только чтение для учеников; при необходимости позже — CRUD для учителя.

## Контракт API

- `GET /api/v1/modules` — список модулей. Query: `platform`, `tag` (опционально).
- `POST /api/v1/modules` — создать курс (teacher). Тело: `{ "title", "description?", "sort_order?" }`.
- `DELETE /api/v1/modules/:id` — удалить курс и все его уроки (teacher).
- `GET /api/v1/modules/:id` — один модуль с вложенными уроками.
- `POST /api/v1/modules/:id/lessons` — добавить урок в курс (teacher). Тело: `{ "title", "description?", "lesson_type?", "sort_order?", "steps?" }`.
- `GET /api/v1/lessons/:id` — урок по id (включая шаги, материалы, теги, чек-лист; счётчики лайков/дизлайков и `user_reaction` при авторизации).
- `DELETE /api/v1/lessons/:id` — удалить урок (teacher).
- `PUT /api/v1/lessons/:id/reaction` — поставить лайк/дизлайк уроку. Тело: `{ "reaction": "like" | "dislike" }`. JWT.
- `DELETE /api/v1/lessons/:id/reaction` — убрать свою реакцию. JWT.

## Связи

- Прогресс (progress) ссылается на `lesson_id` и `user_id`.
- Родительский дашборд читает уроки через тот же API и прогресс по `user_id`.

## Решения

- Модули и уроки отдаются без авторизации (публичное чтение).
- Теги хранятся в таблице `lesson_tags` (lesson_id, tag).
- Тип урока: `theory` | `practice` | `project`.
- **Контент шагов урока** хранится в поле `lesson_steps.content` в формате **Markdown** (GFM). На фронте рендерится через `react-markdown`: абзацы, списки, блоки кода (тройные обратные кавычки), инлайн-код, ссылки, выделение.
- **Картинки**: Markdown `![alt](url)`. Кнопка «Картинка» в редакторе вставляет шаблон.
- **YouTube**: ссылка на YouTube в Markdown (`[текст](https://www.youtube.com/watch?v=ID)` или `[текст](https://youtu.be/ID)`) рендерится как встроенный плеер. Принимаются только домены youtube.com и youtu.be. Кнопка «YouTube» в редакторе вставляет шаблон.

## Безопасность контента

- Создание и изменение уроков (в т.ч. контент шагов) доступно только роли **teacher**.
- Контент шагов (`lesson_steps.content`), заголовки шагов, описания уроков и модулей **санитизируются на бэкенде** (пакет `internal/sanitize`, bluemonday) перед записью в БД: удаляются все HTML-теги, что исключает XSS при любом способе рендера.
- Лимиты длины: заголовок — 500 символов, описание — 10 KB, контент шага — 100 KB, шагов в уроке — не более 200.
