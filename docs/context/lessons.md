# Домен: Каталог уроков (модули, уроки, шаги, материалы)

**Обновлено:** 2025-02-09

## Назначение

Каталог учебного плана: дерево модуль → урок → шаги; материалы и теги к урокам. Только чтение для учеников; при необходимости позже — CRUD для учителя.

## Контракт API

- `GET /api/v1/modules` — список модулей. Query: `platform`, `tag` (опционально).
- `GET /api/v1/modules/:id` — один модуль с вложенными уроками.
- `GET /api/v1/lessons/:id` — урок по id (включая шаги, материалы, теги, чек-лист).

## Связи

- Прогресс (progress) ссылается на `lesson_id` и `user_id`.
- Родительский дашборд читает уроки через тот же API и прогресс по `user_id`.

## Решения

- Модули и уроки отдаются без авторизации (публичное чтение).
- Теги хранятся в таблице `lesson_tags` (lesson_id, tag).
- Тип урока: `theory` | `practice` | `project`.
- **Контент шагов урока** хранится в поле `lesson_steps.content` в формате **Markdown** (GFM). На фронте рендерится через `react-markdown`: абзацы, списки, блоки кода (тройные обратные кавычки), инлайн-код, ссылки, выделение.
