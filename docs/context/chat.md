# Домен: Чат с Gemini (история диалогов по урокам)

**Обновлено:** 2025-02-13

## Назначение

Чат с ИИ-помощником по уроку (Gemini). История сохраняется по пользователю и уроку. Пользователь может очистить свою историю чата.

## Контракт API

- `POST /api/v1/chat` — отправить сообщение в Gemini. Тело: `{ "lesson_id", "lesson_context", "messages" }`. Ответ: `{ "text" }`. Auth: JWT.
- `GET /api/v1/chat/:lessonId/history` — история чата текущего пользователя по уроку. Ответ: `{ "messages": [{ "role", "text" }] }`. Auth: JWT.
- `DELETE /api/v1/chat/:lessonId/history` — очистить историю чата по уроку. Ответ: 204 No Content. Auth: JWT.

## Связи

- История хранится в таблице `chat_messages` (user_id, lesson_id, role, text, created_at).
- Привязана к уроку и пользователю.

## Решения

- Роль сообщения: `user` | `model`.
- История загружается при открытии урока (если пользователь авторизован).
- Сохранение: при отправке сохраняем сообщение пользователя и ответ модели.
