# Контекст для агентов

В этой папке лежат **текстовые описания по доменам** — память платформы для согласования агентов и разработчиков.

## Как пользоваться

- **Перед изменением кода домена** — прочитай соответствующий файл (например, `lessons.md` при правке каталога уроков).
- **После изменения контракта API или поведения** — обнови описание в нужном файле (эндпоинты, поля, решения).
- **Новая фича** — добавь новый файл по шаблону (назначение, контракт, связи, решения) и обнови этот README.

## Файлы

| Файл | Домен |
|------|--------|
| [lessons.md](lessons.md) | Каталог: модули, уроки, шаги, материалы |
| [auth.md](auth.md) | Пользователи, роли, JWT, эндпоинты auth |
| [progress.md](progress.md) | Прогресс по урокам и чек-листам |
| [comments.md](comments.md) | Комментарии пользователей к урокам |
| [parent-dashboard.md](parent-dashboard.md) | Дашборд родителя, доступ к прогрессу учеников |
| [api-contract.md](api-contract.md) | Сводка эндпоинтов и форматов (выжимка OpenAPI) |

В `.cursor/rules` добавлено правило: перед правкой домена читать `docs/context/<domain>.md`, после изменения API — обновлять описание.

**Дата последнего обновления раздела:** при значимых изменениях обновляй дату в начале или в конце файла.
