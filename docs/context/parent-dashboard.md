# Домен: Родительский дашборд

**Обновлено:** 2025-02-09

## Назначение

Просмотр списка пользователей (учеников) и прогресса выбранного ученика. Доступно только пользователям с ролью `teacher`.

## Контракт API

- `GET /api/v1/users` — список пользователей (только для teacher). Ответ: массив `User`.
- `GET /api/v1/users/:id/progress` — прогресс пользователя с id (только для teacher). Ответ: тот же формат, что и `GET /api/v1/progress`.

## Связи

- Использует домен users (проверка роли, список пользователей) и progress (получение прогресса по user_id).

## Решения

- Проверка роли выполняется в middleware/handler: после извлечения user_id из JWT проверяется роль; при role != teacher возвращается 403.
- Эндпоинты зарегистрированы с middleware `RequireTeacher` перед хендлером.
