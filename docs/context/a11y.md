# Доступность (A11y)

**Обновлено:** 2026-02-17

## Что сделано

- **ConfirmModal**: фокус в модалке, ловушка Tab, закрытие по Escape (см. компонент).
- **Страница урока**: секции с `aria-labelledby` / `id` у заголовков; чек-лист — подписи к чекбоксам (`aria-label` / текст в `<label>`); блок реакций — `role="group"` и `aria-label`.
- **Симулятор (LedBlinkSimulator)**:
  - контейнер: `role="region"`, `aria-label="Тренажёр: мигающий светодиод"`;
  - кнопки «Запуск»/«Стоп»: `aria-label`, `aria-pressed` у «Запуск»;
  - редактор кода: `id`, `aria-label`, `aria-describedby` на подсказку;
  - LED: `aria-live="polite"` для объявления смены состояния (при необходимости).
- **PageWithToc**: сайдбар с `aria-label`, навигация — `aria-label="Навигация по урокам"`, текущий урок — `aria-current="page"`; ручка ресайза — `aria-label`, `aria-valuenow` / `aria-valuemin` / `aria-valuemax`.

## Рекомендации

- Для сложных интерактивных блоков (симулятор, редакторы) по возможности обеспечить навигацию с клавиатуры (Tab, Enter, Escape).
- Периодически проверять фокус и озвучку в скринридере (NVDA, VoiceOver).
- Для образовательного контента важна читаемость и контраст (учитывать выбранную тему).
