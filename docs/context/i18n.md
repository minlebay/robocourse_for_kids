# Мультиязычность (i18n)

**Обновлено:** 2026-02-17

## Назначение

Поддержка русского (ru) и английского (en) языков в интерфейсе фронтенда. Выбор языка сохраняется в `localStorage` (`learn_kids_lang`) и применяется ко всем переводимым строкам, форматированию дат и голосовому вводу.

## Реализация

- **Стек:** i18next, react-i18next (без HTTP backend — ресурсы подключаются из `frontend/src/i18n/locales/`).
- **Конфиг:** `frontend/src/i18n/index.ts` — инициализация, язык по умолчанию `ru`, при смене языка обновляются `document.documentElement.lang` и `localStorage`.
- **Локали:** `frontend/src/i18n/locales/ru.ts`, `en.ts` — плоская структура ключей (например `nav.catalog`, `auth.login`, `validation.login_min`).
- **Переключатель:** компонент `LanguageSelector` в шапке (RU / EN).

## Ключи и интерполяция

- Валидация возвращает объекты `{ key, params? }`; в компонентах ошибка показывается как `t(err.key, err.params)`.
- Даты: в компонентах используется текущая локаль (`i18n.language === 'en' ? 'en-US' : 'ru-RU'`) для `toLocaleDateString`.
- Голосовой ввод (LessonChat): `recognition.lang` задаётся из текущей локали (`en-US` / `ru-RU`).

## API и бэкенд

- Сообщения об ошибках API приходят с бэкенда на русском; при необходимости мультиязычных ошибок можно ввести коды ошибок и маппинг на фронте.
- Контент уроков (названия, описания, шаги) не переводится через i18n — это данные из БД.

## Добавление перевода

1. Добавить ключ и значения в `frontend/src/i18n/locales/ru.ts` и `en.ts`.
2. В компоненте использовать `const { t } = useTranslation()` и `t('section.key')` или `t('section.key', { param: value })`.

## Тесты

- В `src/test/setup.ts` подключается `../i18n`, чтобы в тестах был инициализированный экземпляр и переводы (по умолчанию ru).
